Coffee, but no tea is a static multi-page coffee shop website built with HTML, CSS and vanilla JavaScript.

The site includes dedicated pages for about, contact and menu content. The menu page is organized into sections such as Coffee, Cakes, Pies, Brownies, Cookies, Donuts, and Cupcakes.

## Features

- Multi-page static site structure.
- Responsive navigation with menu toggle behavior.
- Google Fonts using Lobster and Open Sans.
- Menu page with multiple product categories.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Quick Start

Clone the repo and open `index.html` in your browser, or use the VS Code Live Server extension.

```bash
git clone git@github.com:angelajholden/coffee-but-no-tea.git
```

## Project Structure

- `index.html` - homepage.
- `about/`, `contact/`, `menu/` - inner pages.
- `images/` and `svg/` - visual assets.
- `script.js` - navigation and page behavior.
- `style.css` - site styles.
